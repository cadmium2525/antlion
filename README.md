# アリジゴク巨大化ゲーム

アリジゴクになって、獲物に砂をかけて巣穴へ落とし、食べて大きくなるブラウザゲームです。
アリから始まり、最後はゾウや恐竜まで食べて羽化を目指します。

## 遊び方

- 画面をタップ（クリック）した場所に砂を飛ばします
- 自分より小さい獲物は1回で落とせます。大きい獲物は何度も砂をかけましょう（ゲージ表示）
- 制限時間内に目標の体長まで育つと次のラウンドへ。全5ラウンド
- 最後に羽化したウスバカゲロウの大きさがスコアで決まり、結果カードを画像保存・Xに投稿できます

## ローカルで動かす

ビルドは不要です。静的ファイルをそのまま配信するだけで動きます。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

（ES Modules を使うため、`index.html` をファイルとして直接開くのではなく、HTTPサーバー経由で開いてください）

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面とUI |
| `src/main.js` | ゲーム進行・入力・カメラ・調整用の数値 |
| `src/prey.js` | 獲物の種類とローポリモデル |
| `src/creatures.js` | アリジゴクとウスバカゲロウのモデル |
| `src/world.js` | 砂地・巣穴・小石などの地形 |
| `src/card.js` | 結果カードの描画、スコア→翼開長の換算 |
| `src/audio.js` | Web Audio で合成する効果音 |
| `lib/three.module.min.js` | Three.js r160（MIT License, `lib/three.LICENSE`） |

## 調整用の数値（仮）

企画書で未決定の項目は仮の値で実装しています。主に `src/main.js` 冒頭で変更できます。

- ラウンド数・制限時間・目標体長: `ROUNDS`
- 成長の速さ: `GROW_K`
- 大きな獲物に必要な砂の回数: `hpFor()`
- 砂の着弾範囲: `SPLASH_K`
- スコア→翼開長の換算とランク名: `src/card.js` の `wingspanCm()` / `RANKS`
